# 우드컷 — 목공 재단 최적화 PWA

부재 목록만 입력하면 **필요한 원장(합판) 수**와 **최적 재단 배치도**를 계산해 주는 목공 재단 도우미입니다.
설치형 웹앱(PWA)이라 휴대폰·태블릿 홈 화면에 추가할 수 있고, 한 번 열어두면 오프라인(작업장)에서도 동작합니다.

## 주요 기능

- **판재 재단 최적화**: 길로틴 컷(한 방향으로 끝까지 자르는 방식) 기준 2D 배치 — 실제 테이블쏘/판넬쏘 작업 순서로 자를 수 있는 배치만 생성
- **각재 재단 최적화**: 다루끼(30×30)·투바이(38×89) 등 길이 부재의 1D 배치 — 규격(단면)별로 묶어 원자재 개수를 최소화하고, 원자재별 컷 배치도 제공
- **톱날 두께(kerf) 반영**: 부재 사이마다 톱날 손실을 계산 (판재/각재 각각 설정)
- **가장자리 손질(trim)**: 원장 4변·각재 양 끝의 파손·모서리 불량 여유 반영
- **결 방향 고정**: 부재별로 회전 허용/금지 설정 (집성목·무늬목 결 방향 유지)
- **재단 배치도**: 원장별 SVG 도면 + 부재 이름/치수 표시, 인쇄 최적화
- **수율/자재비**: 판재·각재 수율(%), 가격 입력 시 예상 자재비 합산
- **자투리 목록**: 다음 작업에 쓸 수 있는 남는 판재 조각·각재 길이 정리
- **일괄 입력**: `이름 가로 세로 수량` 형식 텍스트 붙여넣기
- **자동 저장**: 입력값을 기기(localStorage)에 자동 저장

## 사용 방법

1. 원장 규격 선택(기본 2440×1220) 및 톱날 두께 확인
2. 부재 목록 입력 — 결 방향을 지켜야 하는 부재는 "회전 허용"을 끄기
3. **재단 계산하기** → 원장 수·수율·배치도 확인
4. 필요하면 **배치도 인쇄**로 작업장에서 사용

단위는 모두 **mm**입니다.

## 로컬 실행

빌드 과정이 없는 순수 정적 웹앱입니다. 아무 정적 서버로 열면 됩니다.

```bash
# 방법 1
npx serve .
# 방법 2
python3 -m http.server 5173
```

`file://`로 직접 열면 모듈/서비스워커가 동작하지 않으니 꼭 HTTP로 서빙하세요.

## 배포 (GitHub Pages)

저장소 **Settings → Pages → Branch: main, / (root)** 선택 후 저장하면
`https://<계정>.github.io/<저장소>/` 주소로 배포됩니다. 모든 경로가 상대 경로라 하위 경로 배포도 문제없습니다.

배포 후 정적 파일을 수정했다면 `sw.js`의 `VERSION` 문자열을 올려야 사용자 캐시가 갱신됩니다.

## 개발

```bash
npm test        # 재단 엔진 테스트 (node --test)
npm run icons   # PWA 아이콘 재생성 (tools/gen-icons.mjs)
```

### 구조

```
index.html            화면
css/style.css         스타일 (인쇄/모바일 대응 포함)
js/optimizer.js       판재(2D) 재단 최적화 엔진 (순수 모듈, DOM 무관)
js/lumber.js          각재(1D) 재단 최적화 엔진 (순수 모듈, DOM 무관)
js/render.js          배치도 SVG 렌더링 (판재 시트 + 각재 바)
js/app.js             UI 로직, 저장, PWA 등록
sw.js                 서비스워커 (오프라인 캐시)
manifest.webmanifest  PWA 매니페스트
tools/gen-icons.mjs   아이콘 생성 (의존성 없음)
tests/                엔진 테스트
```

### 알고리즘 메모

**판재(2D)**: 길로틴 분할 기반 빈 패킹으로, 정렬 4종 × 자리 선택 휴리스틱 3종(BSSF·BLSF·BAF) × 분할 규칙 3종
조합을 모두 계산한 뒤 **(원장 수 최소 → 자투리가 한 장에 몰리는 배치 → 최대 자투리 크기)** 순으로
가장 좋은 결과를 선택합니다. 부재가 아주 많으면(800개 초과) 검증된 조합만 사용해 계산 시간을 제한합니다.

**각재(1D)**: 규격(단면)별로 묶은 뒤, 원자재 1개씩 "가장 꽉 채우는 부재 조합"을 분기한정 탐색
(노드 상한으로 시간 제한)으로 찾아 순서대로 채웁니다. 단순 FFD(First Fit Decreasing) 결과와
비교해 더 적은 원자재를 쓰는 쪽을 채택하므로 FFD보다 나빠지지 않습니다.
